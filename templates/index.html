{{ ic('info') }} Sobre o Simulador Termo-Hidráulico

Esta ferramenta modela o decaimento axial de temperatura de um fluido incompressível (água) escoando em regime permanente no interior de uma tubulação cilíndrica isolada termicamente, comparando o desempenho com uma tubulação exposta diretamente ao ambiente.

Modelo Matemático Utilizado

A temperatura ao longo do comprimento x é obtida pelo balanço diferencial de energia:

T(x) = Tamb + (Tin − Tamb) · exp( −F · x / (R'total · ṁ · cp) )

Onde a resistência térmica linear total por metro de tubulação (R'total) combina condução radial na camada isolante e convecção externa:

R'total = ln(r2 / r1) / (2π · kiso) + 1 / (hext · 2π · r2)
